# Data

Dataset kompetisi tidak disimpan atau dibagikan ulang melalui repo ini.

## Cara menyiapkan data

1. Buka [halaman data Kaggle Titanic](https://www.kaggle.com/competitions/titanic/data).
2. Masuk ke Kaggle dan setujui aturan kompetisi bila diminta.
3. Unduh lalu ekstrak file ke folder lokal `data/raw/`.
4. Pastikan folder tersebut berisi `train.csv`, `test.csv`, dan `gender_submission.csv`.

Folder `data/raw/` diabaikan oleh Git. Orang lain harus memperoleh dataset langsung dari Kaggle agar aturan sumber data tetap terjaga.
