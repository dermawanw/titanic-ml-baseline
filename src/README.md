# Source code

Folder ini menampung kode yang sudah stabil dan dapat digunakan ulang dari notebook.

Struktur yang direncanakan:

- `features.py` — pembersihan dan pembuatan fitur.
- `train.py` — preprocessing, pelatihan, dan evaluasi lokal.
- `predict.py` — membuat file submission dari model terlatih.

Kode belum ditambahkan sampai baseline notebook berjalan dan keputusan preprocessing sudah terbukti.
