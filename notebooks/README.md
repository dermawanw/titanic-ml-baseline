# Notebooks

Notebook dipakai untuk eksplorasi dan eksperimen, bukan sebagai satu-satunya implementasi proyek.

Rencana notebook:

1. `01-eda.ipynb` — struktur data, missing values, distribusi target, dan kebocoran data.
2. `02-baseline.ipynb` — preprocessing, validation split, model awal, dan metrik.
3. `03-improvement.ipynb` — satu perubahan terukur serta perbandingannya dengan baseline.

Notebook yang dipublikasikan harus dapat dijalankan dari awal hingga akhir tanpa data atau output rahasia.
